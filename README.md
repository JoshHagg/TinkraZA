# TinkraZA

A validation MVP for discovering beginner-friendly, hands-on experiences in Cape Town.

## Run locally

```bash
npm install
npm run dev
```

The local site opens at `http://127.0.0.1:5173`.

## Useful commands

```bash
npm run test:smoke
npm run build
npm start
```

Mock listings live in `src/data/experiences.ts`. Prototype submissions are stored in browser `localStorage` behind the small helpers in `src/utils/storage.ts`.
