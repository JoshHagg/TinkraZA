# TinkraZA

**Discover something new.**

TinkraZA is a South African marketplace designed to help people discover creative workshops, hands-on experiences, and new hobbies.

The goal is to make finding and booking local experiences as easy as possible, while helping independent workshop providers reach new customers.

## About the Project

Finding interesting activities often means searching across social media, individual websites, and scattered listings.

TinkraZA aims to bring these experiences together in one place, making it easier to explore new interests, plan dates, and find activities to enjoy with friends.

## Features

The current version is an early-stage marketplace demo focused on validating demand.

- Browse and discover creative experiences
- Explore workshops across different categories
- Responsive interface for desktop and mobile
- Email signup for early access
- Initial Supabase integration

## Tech Stack

- **Frontend:** React, TypeScript, Vite
- **Database:** Supabase (PostgreSQL)
- **Styling:** CSS
- **Version Control:** Git and GitHub

## Getting Started

### Prerequisites

- Node.js
- npm
- A Supabase project

### Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
cd YOUR_REPOSITORY
```

Install dependencies:

```bash
npm install
```

Create a `.env.local` file in the project root:

```env
VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_ANON_KEY=your_publishable_key
```

Start the development server:

```bash
npm run dev
```

## Project Status

**Early-stage / Validation**

TinkraZA is currently focused on validating interest from South African workshop providers and potential customers.

Future development may include:

- Provider onboarding and management
- Workshop availability and scheduling
- Online bookings and payments
- Customer accounts
- Provider dashboards

These features will be prioritised based on feedback and demonstrated demand.

## Vision

To become South Africa's go-to platform for discovering and booking creative workshops and hobby experiences.
